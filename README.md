# PhoneHub - 手机与电脑极速文件中心与协同控制台

<p align="left">
  <b>简体中文</b> | <a href="README_EN.md">English</a>
</p>

PhoneHub 是一款轻量、极速、无感交互的 Android 手机与 Windows 电脑协同控制中心。


完全基于 Android 原生 **ADB 高速数据管道** 开发，**无需在手机端安装任何第三方常驻 App**，彻底摆脱路由器网段隔离、NAT、TUN 虚拟网卡代理和局域网广播限制，永不杀后台、不产生额外耗电。

---

## ✨ 核心特性

### 📂 1. 极速手机文件管理系统
- **多级面包屑导航**：动态路径穿梭（如 `手机存储 > Download > WeiXin`），支持任意路径直达与上一级返回。
- **快捷常用目录书签**：
  - 📥 下载目录 (`/sdcard/Download`)
  - 📸 相机照片 (`/sdcard/DCIM/Camera`)
  - 📱 屏幕截图 (`/sdcard/DCIM/Screenshots`)
  - 🟢 微信接收文件 (`/sdcard/Download/WeiXin`)
  - 🐧 QQ 接收文件 (`/sdcard/Download/QQ`)
  - 🎵 音乐录音 (`/sdcard/Music`)
  - 📁 手机内部存储根目录 (`/sdcard`)
- **全域拖拽极速上传**：将电脑上的任意文件（APK、压缩包、图片、视频）直接拖入页面，自动推送到当前打开的手机目录并刷新媒体库。
- **批量处理支持**：
  - 支持多选项目（一键全选 / 单选）
  - ⬇️ **批量下载到电脑桌面**
  - 🗑️ **批量彻底删除**
- **文件操作矩阵**：
  - ⬇️ 单文件毫秒级下载到桌面
  - 🖼️ 图片高清弹窗预览（Lightbox 模式，无需下载即点即看）
  - 📁 新建文件夹
  - ✏️ 原地重命名
  - 🗑️ 安全删除（带二次确认与系统根目录防误删保护）
- **实时搜索与排序**：文件名即时过滤，支持按时间（最新优先）、文件名、文件大小排序。

---

### 🖥️ 2. 原生满血硬件加速投屏
- **🚀 144Hz 极客满血高刷档位**：
  - 针对红米 Note 11T Pro（天玑 8100 + 144Hz 顶级 LCD）定制。
  - 参数：`--max-fps=144 --video-codec=h264 -b 20M --keyboard=uhid --mouse=uhid`
  - 享受媲美原生显示器的 144FPS 竞技级超低延迟投屏与硬件级键鼠直控。
- **🌙 天玑微光防发热档位**：
  - 彻底解决联发科芯片物理熄屏导致硬件编码器断流黑屏的痛点。
  - 自动将手机屏幕物理亮度压到极限微光，屏幕不发热、电脑画面满帧正常呈现。
- **物理电源键**：一键唤醒 / 熄灭手机屏幕。

---

### 💬 3. 短信与 2FA 验证码中心
- **实时短信列表**：准确呈现发件人、日期时间与正文。
- **验证码智能识别**：自动高亮 4~8 位数字验证码，配备 **`🔑 复制验证码`** 按钮一键存入 Windows 剪贴板。
- **后台无感监听**：内置后台通知同步守护，新收到的验证码会自动推送到电脑剪贴板并弹出 Windows 原生 Toast 提醒。
- **电脑端发送短信**：输入号码与正文直接通过手机基带发送。

---

### ⚡ 4. 跨屏文字速传 & 双向剪贴板
- 电脑复制的长文本、链接、代码，点击 **`📋 电脑剪贴板`** 瞬时注入手机当前输入框。
- 支持在输入框键入任意文字按回车直接注入手机。

---

### 🧹 5. 手机深度清理与性能加速
- **⚡ 一键释放系统级缓存**：调用 `pm trim-caches 1000G` 深度回收应用临时缓存。
- **🛑 强力清理后台流氓应用**：调用 `am kill-all` 释放后台驻留内存。
- **🚫 一键停用小米广告全家桶**：免 Root 停用 `msa`、埋点监控与快应用等预装广告组件。

---

### 🌐 6. 原生中英双语即时切换 (Bilingual Support)
- 顶部状态栏集成原生中英双语一键切换按钮（`🌐 English` / `🌐 简体中文`）。
- 毫秒级无刷新更新全站所有书签、操作按钮、批量处理条、文件表格、提示气泡与系统弹窗。
- 自动持久化本地语言偏好设置（`localStorage`）。

---

## 🚀 启动与使用

### 快速启动
双击桌面的 **`PhoneHub.lnk`** 或运行根目录下的 `phonehub/launch_phonehub.vbs` 即可无声启动后台服务并唤起独立应用窗口。

### 手动命令行启动
```bash
cd phonehub
python server.py 18080
```
浏览器访问：`http://127.0.0.1:18080/`
